- **gbadisasm** — GBA disassembler. https://github.com/jiangzhengwenjz/gbadisasm
  commit `940def2c91d678ee671716b8b44a2223c0ff2c62` (2023-07-14). Used for Y3: it turns
  `private/baserom.gba` plus the config written by `tools/make_disasm_cfg.py` into the assembly
  that `make compare` builds back into the ROM. Cloned (not vendored) into
  `private/tools/gbadisasm/`; nothing under `private/` is committed.

- **Capstone 3.0.5-rc2** — disassembly framework, bundled inside gbadisasm as
  `capstone-3.0.5-rc2.tar.gz` and built from source by gbadisasm's Makefile with
  `CAPSTONE_ARCHS="arm"`. Licence: BSD-3-Clause (`capstone-3.0.5-rc2/LICENSE.TXT`).
- **agbcc** — the GBA C compiler, i.e. gcc 2.9 hacked for the ARM7TDMI, built from
  `https://github.com/pret/agbcc` at commit `da598c1d918402c42c0c0d7128ba14567f3175e9` (2026-10-24):
  the clone is `private/tools/agbcc-src/`, its `build.sh` built `bin/agbcc`, `bin/old_agbcc` and
  `bin/agbcc_arm` plus `libgcc.a`/`libc.a` (host gcc 16.2.1, arm-none-eabi binutils 2.47), and its
  `install.sh` put them under `private/tools/agbcc/` (bin/, include/, lib/) — the layout
  `scripts/match_func.sh` expects. The banner reads `Generated by gcc 2.9-arm-000512 for Thumb/elf`.
  Only `bin/agbcc` and `bin/old_agbcc` are used, chosen per C file (A37). Licence: the GNU GPL
  (agbcc is derived from gcc 2.9 / GPL-2 — the same terms the pret project ships it under). Used
  for Y5: it compiles `src/funcs/*.c` into the exact ROM bytes (see `docs/decomp.md` §5). The
  invocation (flags, include paths, the `cpp`/`agbcc`/`as` sequence) is copied from pokefirered's
  Makefile. Nothing under `private/` is committed.

  `OpenJDK21U-jdk_x64_linux_hotspot_21.0.12.1_1.tar.gz` (198 MiB) from

  only. Licence: GNU GPL v2 with the Classpath Exception.

- **decomp-permuter** (github.com/simonlindholm/decomp-permuter, commit
  `8556c81d80d1c1af98a858c8f4dc951357f29139`, 2026-10-06) — randomized search for C that a
  compiler turns into the ROM's bytes; the search's score is a hint, never a check. Used by
  `scripts/permute_func.sh` / `tools/permute_func.sh` to hunt near misses. Cloned into
  `private/tools/decomp-permuter/` (13 MiB with its git history) by `scripts/decomp_tools.sh`.
  Licence: MIT (`LICENSE`).
- **asm-differ** (github.com/simonlindholm/asm-differ, commit
  `0dd09af8f8008f1f880327cf0aca3b26d2562ea2`, 2026-09-06) — the side-by-side assembly diff
  (the viewer decomp.me uses). Used by `scripts/diff_func.sh` / `tools/diff_func.sh`, which writes
  the `diff_settings.py` it reads. Cloned into `private/tools/asm-differ/` (913 KiB) by
  `scripts/decomp_tools.sh`. Licence: MIT (`LICENSE`).
- **Python packages for those two** — `toml` (permuter settings), `colorama` and `watchdog`

- **ghidra-mcp** (github.com/bethington/ghidra-mcp, commit

  `.sha512` Apache publishes next to it; the Ghidra jars the build needs are installed into
  `private/tools/maven/repo` (never `~/.m2`). Licence: **Apache-2.0** (`LICENSE`).
