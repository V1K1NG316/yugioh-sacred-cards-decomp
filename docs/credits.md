- **agbcc** — the GBA C compiler, i.e. gcc 2.9 hacked for the ARM7TDMI, taken from
  `D:\Custom_Pokemon\private\base\pokefirered\tools\agbcc\` (the copy used by a local pokefirered
  build) and copied to `private\tools\agbcc\` (bin/, include/, lib/) — the original was not
  modified, and nothing under `private\` is committed. Its banner reads
  `Generated by gcc 2.9-arm-000512 for Thumb/elf`; `bin/` also holds `agbcc_arm` and
  `old_agbcc`, neither used yet. Licence: the GNU GPL (agbcc is derived from gcc 2.9 / GPL-2 —
  the same terms the pret project ships it under). Used for Y5: it compiles `src/funcs/*.c` into
  the exact ROM bytes (see `docs\decomp.md` §5). The invocation (flags, include paths, the
  `cpp`/`agbcc`/`as` sequence) is copied from pokefirered's Makefile.
